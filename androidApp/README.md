# Android 测试版

这是照片无障碍描述工具的原生 Android 版本，使用 LiteRT-LM 0.15.0 在手机本地运行 Qwen3.5 4B 多模态模型。

首次打开只检测本地文件。缺少模型时，TalkBack 可访问的弹窗会说明约 5.26GB 下载量；只有选择“下载并自动配置”后才联网。下载支持断点续传，并显示进度、已下载/总大小和实时速度，完成后执行 SHA-256 校验。

照片批量识别后默认直接写入已勾选项目。每张照片也可单独取消、编辑描述或单独写入。当前测试版只安全写入 JPEG 与 PNG；写入时使用原始扁平 XMP packet，并校验直接字段、错误嵌套字段、文件名、尺寸和解码像素签名。

构建：

    ./gradlew testDebugUnitTest assembleDebug
