# Android v0.7.0 测试版

这是照片无障碍描述工具的原生 Android 版本。LiteRT-LM 0.15.0 随 APK 提供，视觉模型按需下载，照片推理完全在手机本地完成。

首次打开会用 TalkBack 可访问的弹窗询问推理引擎：

- LiteRT-LM 智能加速：优先 GPU，不兼容时自动回退 CPU。
- LiteRT-LM CPU 兼容模式：始终使用 CPU，优先稳定性。

设置区域可随时独立切换引擎与模型。模型列表包括 Qwen 3.5 4B、Gemma 4 E2B、Gemma 4 E4B、Gemma 3n E2B 和 Gemma 3n E4B。选择模型时会朗读下载大小、Android/macOS/Windows 适用状态、内存和设备级别；已安装模型直接加载，未安装模型才询问下载。Windows 版软件尚未提供。多个模型可以并存，也可单独移除以释放空间。

下载支持断点续传，并显示当前阶段、已下载/总大小、实时速度、连接次数和等待原因。15 秒没有新数据会报告停滞，30 秒读取超时后自动断点重试，最多三次；也可随时取消并保留进度。失败会明确区分网络、DNS、代理证书、HTTP、许可、令牌、空间、长度和 SHA-256 问题。Gemma 3n 官方仓库受 Gemma 许可保护，需要用户先在 Hugging Face 接受许可，并只为该次下载输入读取令牌；应用不保存令牌。其余三个模型不需要账号或密钥。

模型输入会先按方向旋转、缩小到最长边 1280 像素并压缩为 JPEG，减少发热、内存和识别时间，同时不修改原照片。模型发现数量、文字或空间关系存在疑点时才启动独立视觉校对；校对未通过会自动定向修正和复核。

照片批量识别后默认直接写入已勾选项目。列表只显示序号，不显示乱码原文件名，并列出格式、尺寸和拍摄时间。描述编辑框默认隐藏，点击“编辑描述”才展开。可单独写入、批量写入，或选择文件夹批量导出按 1、2、3 编号的结果。

当前测试版只安全写入和导出 JPEG 与 PNG；其他格式可以识别，但不会未经同意静默转换格式。写入时使用原始扁平 XMP packet，并校验直接字段、错误嵌套字段、文件名、尺寸和解码像素签名。批量处理每秒播放一次低音量进度音，音调随进度升高，50% 和 100% 使用不同提示音。

当前工作区在下次启动时会清空，其中已有描述的照片进入默认折叠的历史区域。历史批次按“年月日 时分秒”命名，默认保留 30 天，可改为 7、30、90 或 365 天。支持删除单条、单批次、全部历史和清空当前工作区；外接键盘可按 Meta/Command-退格删除当前焦点素材。所有删除只清理软件记录，不会删除手机媒体库中的原照片或导出文件。

构建：

    ./gradlew testDebugUnitTest assembleDebug
